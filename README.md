# Cache Trainer

An interactive revision site for cache memory (direct-mapped, set-associative and fully associative caches, tag/index/offset, miss rates, write policies and timing formulas). It was built as a personal study aid for a computer architecture course and works in English and Spanish.

It is plain HTML, CSS and JavaScript with no build step: open `index.html`, or use the hosted version at https://joejbaldwin.github.io/cache-trainer/. Progress is saved in your browser only.

This is an unofficial study tool, not course material; check anything important against your own lecture notes.
